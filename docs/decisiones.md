# Decisiones del proyecto

## 001. Disponibilidad de los datos al emitir una estimación

Para estimar la sílice a una hora determinada, solo se usarán como entradas
los datos que el operador habría podido conocer a esa hora. El resultado de
laboratorio de la muestra se utilizará después para evaluar la estimación.

La hipótesis inicial es que cada resultado corresponde a una muestra puntual.
Durante la ingesta se revisará qué documentación existe sobre el muestreo y
qué representa la marca de tiempo del archivo. Si la fuente no lo especifica,
se documentará esa limitación.
